# 动态优化

> 状态说明：当前 `main` 没有在线采样、对照回答、质量评审或自动发布能力。本章描述目标异步评估系统；它不能给在线业务请求施加背压。

动态优化从真实 `auto` 流量中抽样，用受控预算比较候选计划与强基线，再将可信证据交给策略生命周期。它不在用户请求的同步关键路径上运行。

![动态优化流程](/diagrams/dynamic-optimization.svg)

## 抽样资格

只有同时满足以下条件的请求可进入评估：

- 请求使用 `model=auto`。
- 业务响应已完成，且客户端未取消。
- profile 启用了动态优化。
- 请求类型、内容长度和数据策略允许评估。
- 当日预算和样本配额仍有余量。
- 未命中敏感内容排除规则。

显式模型请求不得进入动态评估，也不能影响候选策略的质量结论。

## 异步链路

1. 在线请求只执行业务计划并返回结果。
2. 采样器以非阻塞方式尝试写入有界内存队列。
3. 队列满时直接丢弃评估任务，并增加指标。
4. 工作器原子预留评估预算。
5. 生成必要的对照回答。
6. 先执行确定性检查，再执行匿名成对质量评审。
7. 将脱敏结果聚合到质量统计。

上游凭据只保存在进程内存中，不写入队列持久化、样本表或日志。

## 单样本调用上限

每个样本最多包含：

| 调用 | 上限 | 说明 |
| --- | ---: | --- |
| 实际业务回答 | 1 | 已经发生，不重复生成 |
| 被观察计划 | 1 | 仅在需要重放时生成 |
| 强基线回答 | 1 | 用于质量锚定 |
| 质量评审 | 1 或 2 | 第二次评审只用于高价值或冲突样本 |

不能无限扩展候选集合。评估系统的目的不是在线锦标赛，而是为有限策略变更收集可发布证据。

## 预算预留

预算必须在发起任何评估调用前原子预留：

```text
remaining = daily_budget - reserved_cost - settled_cost
```

若预估成本大于 `remaining`，样本直接跳过。调用完成后用实际成本结算，多余预留归还。业务预算和评估预算分开配置与统计。

## 确定性检查

质量评审前先执行低成本、可解释的检查：

| 检查 | 示例 |
| --- | --- |
| 协议有效性 | JSON 能否解析、工具调用结构是否合法 |
| 格式约束 | 是否满足 JSON Schema、必需字段是否存在 |
| 截断与空响应 | 是否异常结束或没有有效内容 |
| 安全规则 | 是否出现凭据、内部提示或禁止内容 |
| 明确答案 | 可由固定断言验证的数学或代码输出 |

首版禁止运行模型生成的任意代码或 shell 命令。需要执行验证的任务必须使用专门、受限且预先定义的验证器。

## 匿名成对质量评审

质量评审模型看不到模型名、价格和路由原因。A/B 顺序随机；重要样本用交换顺序再次判断，以降低位置偏差。

```json
{
  "winner": "A",
  "confidence": 0.87,
  "scores": {
    "correctness": {"A": 0.95, "B": 0.82},
    "instruction_following": {"A": 0.90, "B": 0.90},
    "completeness": {"A": 0.92, "B": 0.78},
    "safety": {"A": 1.00, "B": 1.00}
  },
  "severe_error": false
}
```

低置信度、交换顺序后冲突或两次评审严重分歧的样本不进入发布统计，但应记录为评估系统健康指标。

## 可信证据

| 可进入统计 | 不可进入统计 |
| --- | --- |
| 确定性检查结果 | 未脱敏的原始提示词 |
| 匿名成对胜负与维度分 | 评审模型看到模型身份后的偏好 |
| 有效性、置信度、严重错误标记 | 超预算后补记的样本 |
| 任务类型和策略版本 | 显式模型流量 |

原始评估任务只在内存中短暂存在。若必须持久化内容，应先经过字段级脱敏和保留期控制。

## 停止条件

以下任一情况应暂停候选评估或阻止发布：

- 严重错误率触及门槛。
- 质量评审冲突率或无效样本率异常上升。
- 预算、队列或上游健康指标异常。
- 样本分布偏离主要任务类型，无法满足分层样本要求。
- 发现凭据、提示词或回答泄露。

## 验收检查

- [ ] 只抽样 `auto` 请求。
- [ ] 在线线程使用非阻塞有界队列。
- [ ] 预算在评估调用前原子预留。
- [ ] 每个样本的回答和质量评审调用数受硬上限约束。
- [ ] 首版不执行任意模型生成代码或 shell。
- [ ] 低置信度和冲突样本不进入发布统计。
