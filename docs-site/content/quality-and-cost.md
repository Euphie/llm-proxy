# 质量与成本

> [!TARGET]
> 路由目标不是“永远选最便宜”，而是在当前 Route 的质量要求内，选择预计完整成本更低的合格模型。

## Route 质量门槛

不同业务的失败代价不同，因此质量目标按 Route 配置，而不是使用一个全局固定百分比。管理员可以从以下模板开始，再修改具体门槛：

- **质量优先**：更保守地使用强模型，适合代码修改和高影响工具任务。
- **均衡**：在质量稳定的前提下扩大低成本模型覆盖。
- **成本优先**：允许更多简单任务使用低成本模型，但仍保留严重错误硬门槛。

门槛可以包含任务成功率、格式通过率、工具正确率、严重退化率和相对强基线差距。严重错误是硬门槛，不能被平均分数抵消。

## 完整成本

一次请求的预计成本必须包含：

```text
任务分析器 + 主回答 + 视觉辅助 + 重试 + Target/模型切换
```

金额使用整数 micro-USD 保存和累加，避免浮点误差。价格快照要记录版本，历史结果不能用今天的价格重新解释。

## 如何估计模型效果

每个模型按 Route、任务类型和必要能力积累结果。样本少时不能直接相信表面胜率，而应使用分层贝叶斯估计：

- 新模型先向同类模型的总体水平收缩；
- 较新的样本权重更高，旧样本逐渐衰减；
- 选择时使用保守置信下界，而不是只看平均值；
- 严重错误单独计数，并作为硬门槛。

这样得到的是“在当前 Route 和任务条件下的可信能力估计”，不是一个永久不变的全局模型权重。
普通候选的证据不足时使用保守先验；置信下界仍未达到 Route 门槛就排除。若没有候选通过，只能使用满足硬约束的强模型基线，否则请求失败。

## 展示分与发布门槛

后台可以把多项指标汇总成 0–100 展示分，并显示 A/B/C/D 等级，帮助管理员快速比较策略。等级只用于展示，不能绕过 Route 质量门槛，也不能直接触发发布。

## 最终选择

1. 先排除能力、上下文、视觉或高风险不合格的模型。
2. 再排除未达到 Route 质量门槛的模型。
3. 对剩余候选比较预计完整成本；成本接近时可再比较延迟和稳定性。
4. 没有可靠低成本候选，或统计不确定性过高时，使用强模型基线。

缺失能力按“不满足”处理，缺失价格按“不可发布”处理，不能把未知值当成零成本或可用能力。
