# 管理控制台

管理控制台位于 `/_admin/`。它只管理转发配置、模型事实和运行策略，不保存调用方密钥。

## 首次使用

首次启动使用账号 `admin`、密码 `admin` 登录，并按页面要求设置至少 10 个字符的新密码。随后后台会进入四步引导：

1. **连接上游**：填写名称、Slug、协议和 Upstream 基础地址。
2. **模型（选填）**：只做普通转发时可以跳过；智能路由依赖这里录入的模型。
3. **Agent 配置**：生成 Claude Code、OpenCode、Codex 或通用客户端配置。
4. **验证请求**：从 Agent 发送一个真实请求，后台会自动检测该 Profile 的累计请求数。

引导页不要求填写 API Key。Agent 仍在每次代理请求中发送自己的认证头。

Profile 的代理路径为：

- 默认 Profile：`/v1/...`
- 指定 Profile：`/<slug>/v1/...`

例如 Slug 为 `coding` 时，Anthropic Messages 地址是 `/coding/v1/messages`。

## 页面说明

| 页面 | 用途 |
|---|---|
| 概览 | 查看运行状态、首次接入进度、Profile 路径和请求数 |
| Profiles | 创建、复制、启停、设为默认或删除 Profile |
| 统计 | 分别查看用量统计、可分页路由轨迹和五维模型表现 |
| 系统 | 更新模型信息库、查看潜在影响、修改管理员密码和导出 Profile JSON |

每个 Profile 使用独立设置页：

| 分区 | 主要操作 |
|---|---|
| 概况 | 查看代理路径、协议、功能状态和下一步操作 |
| 连接 | 修改名称、Slug、协议、Upstream、启用和默认状态 |
| 模型 | 录入精确模型 ID、上下文、输出上限、能力和价格 |
| 智能路由 | 配置参与模型、模型角色、策略、风险规则、模型主动升级和调用预算 |
| 视觉增强 | 配置视觉模型、传输、缓存、限制和提示词 |
| 容错 | 配置普通重试，以及智能路由使用的备用上游节点|
| Agent 配置 | 为当前协议生成兼容客户端配置 |

切换 Profile 分区时，未保存修改会触发离开确认。

## 功能依赖

- 基础转发只需要有效的连接配置。
- 模型目录是选填项；Agent 配置不依赖模型目录。
- 输入、输出、缓存读取和默认缓存写入价格在后台按美元/百万 Token 填写，路由预算按美元填写；
  API 与数据库仍使用整数微美元。未知模型 ID 可从可搜索的模型库套用参数模板。
- 智能路由必须先录入至少两个不同模型，并选择至少两个参与模型。强模型基线和任务分析模型必须引用已录入的精确 ID，实际调用模型还需要输入和输出价格。
- 对比学习依赖已启用的智能路由和可用的质量评审模型。
- 模型主动升级依赖至少一次模型切换预算，所有非强基线候选模型还必须明确支持工具调用；低级模型申请后，代理重放原始请求并只返回更强模型的回答。
- 备用上游节点只用于 `model=auto`；智能路由未启用时，普通重试仍可独立配置。
- 视觉增强启用后必须填写视觉模型；和智能路由同时使用时，该模型还需要视觉、价格、上下文和最大输出能力。

后台会在功能入口显示缺失项和直达链接。服务端保存校验仍是最终边界。

模型 ID 区分大小写。模型被路由角色、Route、视觉或上游节点引用时，后台会阻止删除或改名，并列出需要先处理的引用。关闭智能路由、视觉增强或对比学习只停用运行时行为，不会清空已填写的详细配置。

## 日常操作

1. 从“概览”确认 Profile 已启用并收到请求。
2. 需要接入新客户端时，打开 Profile 的“Agent 配置”。生成内容只保留在浏览器中，真实密钥在 Agent 本地设置。
3. 需要视觉或智能路由时，先补齐“模型”事实，再按页面依赖提示启用功能。
4. 请求异常时打开“统计 → 路由轨迹”查看分类、候选排除原因和调用链；模型质量问题进入“模型表现”。
5. 修改管理员密码或导出配置时进入“系统”。导出文件不包含调用方密钥。

## 更新模型信息库

进入“系统”，在“模型信息库”中查看当前来源、revision、获取日期和模型数，点击
“从 Models.dev 更新”执行一次手动更新。成功后新目录立即用于后台录入建议，无需重启；更新失败则
继续使用旧版本。

更新后页面会扫描全部 Profile 及正式、灰度、评估和草稿策略，列出能力下降、容量变化和价格变化的
潜在影响。报告仅供检查，不会修改已保存的 Profile 或策略。

详细规则见 [Profiles](profiles.md)、[模型能力](models.md)、[图片预处理](vision.md)、[智能路由](intelligent-routing.md)和 [Token 用量统计](statistics.md)。
